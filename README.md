# 🐍 Python Basic Exercises (PyNative)

This repository contains my solutions to the **Python Basic Exercise for Beginners** from [PyNative.com](https://pynative.com/python-basic-exercise-for-beginners/).  
The exercises cover foundational Python concepts and serve as a great way to strengthen problem-solving and coding skills.

---

## 🧩 Topics Covered
- Basic Syntax and Operations
- Control Flow (if-else, loops)
- Functions
- Lists and Tuples
- String Manipulation
