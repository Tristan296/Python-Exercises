# 🐍 Python Basic Exercises (PyNative)

This repository contains my solutions to the **Python Basic Exercise for Beginners** from [PyNative.com](https://pynative.com/python-basic-exercise-for-beginners/).  
The exercises cover foundational Python concepts and serve as a great way to strengthen problem-solving and coding skills.

---

## 📘 Overview

The exercises are organized by topic and gradually increase in difficulty.  
Each script demonstrates the use of Python fundamentals such as loops, conditionals, functions, and data structures.

---

## 🧩 Topics Covered

- **Variables & Data Types**
- **Strings & String Manipulation**
- **Loops & Conditionals**
- **Functions**
- **Lists, Tuples, Sets, and Dictionaries**
- **Input/Output Operations**
- **Number & Math Operations**
- **Formatting and f-Strings**
